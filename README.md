# 🎰 土制量化梭哈机器人

> 严肃学习 FX 久留美精神。几百刀，图一乐：赚了是策略牛逼，亏了是市场不懂我。

挂在 GitHub Actions 上的加密货币自动交易机器人：每小时醒一次，看 K 线、算信号、该梭就梭、该跑就跑，顺手爬点行情数据。默认**模拟盘**，玩明白了再上真钱。

- **交易所**：Gate 现货（底层是 [ccxt](https://github.com/ccxt/ccxt)，想换交易所改一行配置）
- **策略菜单**：趋势 / 动量 / 抄底 / 情绪 / 网格 / 轮动，外加两个对照组（无脑囤币、猴子扔骰子）。全部拿 Gate 真实 K 线、按真实费率回测过，成绩单见下文
- **风控**：止损、止盈、移动止损、熔断（亏到预算的一半自动罢工）
- **爬虫**：恐惧贪婪指数、CoinGecko 热搜、Gate 涨跌榜、股票代币相对正股的溢价（美股周末休市，代币还在 24/7 跑）
- **推送**：微信（Server酱 / PushPlus）、Telegram、Bark

## 策略菜单 & 成绩单

先说怎么考的：9 个标的（BTC、ETH、SOL、DOGE、GT 五个币 + SPYX、QQQX、NVDAX、TSLAX 四个股票代币）× 1h / 4h / 1d 三个周期，全部用 Gate 现货的真实 K 线；手续费 0.2%/边，滑点 0.05%~0.2%，本金 300 USDT。每个策略的默认参数在各周期**前 60% 的历史里挑**，后 40% 当考卷（样本外）。有一点要说清楚：Gate 的 1h / 4h 历史很短（2025-09 / 2022-04 起），有几个策略挑参数时参考了 1h / 4h 的样本内表现，而那段日历时间和日线的样本外有重叠——所以日线的“样本外”不是百分之百干净的考卷，数字偏乐观多少说不准。对照组两个：无脑囤币，和 30 只随机买卖的猴子。完整排行榜在 [research/leaderboard.md](research/leaderboard.md)，`python -m research.leaderboard` 可以自己重算。

### 一句话结论

- **只用日线。** 1 小时级别全军覆没：一年来回几百次，光手续费就能把本金磨掉一大半。4h 也大多输给囤币。
- **加密日线上，动量 / 趋势派确实有点东西**：样本外收益中位数 +100%~+160%（同期囤币 +87%），最大回撤从 76% 压到 35%~47%。但它主要赢在**熊市少亏、山寨币躲过暴跌**；BTC、ETH 的大牛市里照样跑不赢死拿。而且对上运气最好的那 10% 猴子，也只在 1~2 个币上赢了——别把它当印钞机。
- **抄底、网格、“别人恐惧我贪婪”是亏钱的**——不全怪手续费，是这些规则本身在趋势行情里站错了边。最反直觉的一条：恐惧贪婪指数**反着用**才赚——指数涨到 70 上车、跌到 40 下车。
- **股票代币上没有任何策略跑赢囤币**：代币跟正股跟得很紧，机器人在上面赚不到“策略钱”。
- **轮动梭哈**（每天把钱梭进篮子里近 30 天涨得最猛的币）最刺激：样本外 +335%（同期 BTC 囤币 +28%），可最近 12 个月是 -26%，回撤动辄 60%+。纯粹的行情赌注。

“样本外”是每个币最后 40% 的日线（BTC/ETH 从 2022-11 熊市底部起，SOL 从 2024-04，DOGE 从 2023-03，GT 从 2023-10），中间有一轮牛市和现在这轮下跌。排行榜里还有 1h / 4h 和股票代币的表，大部分是一片绿（亏）。

**别叠止损。** 趋势 / 动量策略自带离场规则，研究里给它们再加 `stop_loss = 0.15`、`trailing_stop = 0.25` 基本都更差（割在下一段行情的起点）。只留 `kill_switch` 当保险丝就好。

**手续费是 0.1% 呢？** Gate 帮助中心写的 VIP0 费率是 0.1%（公开接口写 0.2%，以你账户为准）。按 0.1% 重跑一遍（[research/leaderboard-fee0.1.md](research/leaderboard-fee0.1.md)，`python -m research.leaderboard --fee 0.001 --out research/leaderboard-fee0.1.md`）：日线动量派样本外再多 10~20 个点（`tsmom` +162% → +185%），排名不变；4h 和 1h 还是亏。结论不变：手续费减半也救不了高频。

### 轮动梭哈（`strategy = "rotation"`）

多币机器人：每天按近 30 天涨幅给篮子排名，现金全部梭进第一名；第一名自己都没涨就拿现金；新第一名要比手里的多涨 10 个百分点才换车（省手续费）。这是整个菜单里最“梭哈”的一个，也是方差最大的一个——**结果极度依赖你从哪天开始跑**：

| 区间（加密篮子 BTC/ETH/SOL/DOGE/GT · 日线） | 轮动 | 等权囤币 | BTC 囤币 | 轮动最大回撤 | 复现 |
|---|---|---|---|---|---|
| 2020-08 ~ 2024-05（选参数用的样本内） | +10249% | +2220% | +456% | 65% | `--days 2257 --split 0.6` |
| 2024-05 ~ 2026-10（样本外） | **+335%** | -12% | +28% | 63% | 同上 |
| 最近 3 年：2023-11 ~ 2026-10 | +733% | +85% | +120% | 63% | `--days 1095` |
| 最近 12 个月：2025-11 ~ 2026-10 | **-26%** | -42% | -29% | 44% | `--days 365` |

复现：`python -m bot.rotation --bot alt-rotation --offline` 加上表里的参数（先跑一次 `python -m research.harness --download` 把 K 线缓存下来）。

翻译成人话：牛市 / 山寨季它能抓住最猛的那个币，赚到离谱；熊市里“第一名都没涨就拿现金”只能少亏一点，挡不住来回挨打（最近 12 个月亏 26%，和死拿 BTC 差不多）。篮子是事后挑的（幸存者偏差），收益主要来自少数几段大行情，63% 的回撤是常态。4h 版本和股票代币篮子回测都亏，别用。

### 股票代币（xStocks / Ondo）

Gate 上有 TSLAX、NVDAX、SPYX、QQQX（xStocks）和 TSLAON 这类 Ondo 代币，24/7 交易。研究笔记 [research/notes/stock_tokens.md](research/notes/stock_tokens.md) 的结论：

- **跟得很紧**：美股开盘时相对正股的偏离中位数 0.05%~0.12%，夜里按股指期货推算也只有 0.06%~0.07%；代币价格里自带税后分红再投资，所以会慢慢比正股“贵”一点，那不是溢价
- **周末的代币报价有信息量**：能预测周一开盘跳空的大半，但扣掉 0.6% 的来回成本，没有能交易的规律
- **没有策略跑赢囤币**；16 个月的数据也证明不了任何正常策略。想玩就日线囤 SPYX/QQQX（config 里有个默认关闭的 `spyx-hodl`）
- 拆股 / 分红会改变账户里的代币数量，机器人账本跟不上，遇到要手动核对

### 2026-10-30 这会儿机器人在想什么

用当天的 Gate 行情空跑了一遍：**全员空仓**。BTC 近 14 天 -5.2%，没到动量的上车线；篮子里 5 个币近 30 天全是负收益（最强的 BTC 也 -6.8%），轮动拿现金；恐惧贪婪指数 51（今天已经掉到 30），离上车线 70 远着呢。熊市里，机器人比人冷静。只有猴子说“梭！”。


## 它是怎么跑的

```
GitHub Actions（每小时第 7 分钟）
└─ python -m bot.run
   ├─ 拉最近的已收盘 K 线（Gate 公共接口，不需要 key）
   ├─ 策略 → 目标仓位 0~1（1 = 梭哈，0 = 空仓）
   ├─ 风控覆盖：止损 / 止盈 / 移动止损 / 熔断
   ├─ 目标仓位 vs 当前仓位 → 下市价单（模拟盘假装成交，实盘真下单）
   └─ 记账 → 推到 bot-data 分支（下次运行接着用）
```

几个设计上的讲究：

- **幂等的“目标仓位”写法**：策略不说“买/卖”，只说“我现在应该持有多少”。GitHub 的定时任务经常延迟、偶尔重跑或漏跑，这种写法跑几次都不会重复下单。
- **回测和实盘是同一套代码**：`decide → plan_order → 成交 → 记账`，回测只是把成交换成“下一根 K 线开盘价 + 手续费 + 滑点”。
- **每个机器人只认自己的账本**：预算多少、手里多少币、多少现金。实盘时下单金额同时受账本和交易所真实余额限制，账户里别的钱它不碰。
- **掉单自愈**：每笔实盘订单都带备注（Gate 的 `text` 字段），万一下了单但账本没存上（下单超时、推送失败），下次运行会按备注把订单认领回来，补进成交记录，止损单的冷静期也会接着算。拉不到 `bot-data` 分支（网络抽风）时这次直接不跑，绝不拿空账本交易。
- **状态放 `bot-data` 分支**：机器人每小时提交一次，但只提交到 `bot-data`，`main` 只放代码和配置，你改配置永远不会和机器人冲突。

## 快速开始

### 1. 本地先玩（可选）

```bash
pip install -r requirements-dev.txt
```

```bash
python -m pytest
```

```bash
python -m bot.backtest --strategy tsmom --symbol BTC/USDT --timeframe 1d --days 1500
```

```bash
python -m bot.run --dry-run
```

`--dry-run` 只看信号不下单不存盘。不加就是真的跑一步模拟盘（状态写到 `state/paper/`）。

### 2. GitHub 上的模拟盘：默认就开着

代码在默认分支上，模拟盘机器人每小时、爬虫每 3 小时就会自动跑，什么都不用配。想关掉：仓库 **Settings → Secrets and variables → Actions → Variables** 里新建 `BOT_ENABLED` = `false` 或 `CRAWLER_ENABLED` = `false`。

**Actions** 页面能看到「梭哈机器人」每小时跑一次，每次运行的 Summary 里有一张表：每个机器人做了什么、净值多少。账本、成交记录、净值曲线在 `bot-data` 分支的 `state/` 目录，爬虫数据在 `data/` 目录。

想马上跑一次：Actions → 梭哈机器人 → Run workflow。

### 3. 上实盘

完整的一步一步版本（装 runner、Gate 子账户和 key、空跑体检、日常操作、出岔子会怎样）在 **[docs/live.md](docs/live.md)**。下面是要点。

**先过这一关**：Gate 用户协议（第 2.5 条）把**美国和中国大陆**都列为受限地区，在受限地区使用可能被限制或冻结账户。你能不能用、用了担什么风险，只有你自己能判断；这个项目不提供任何绕过地区限制的办法。

确定要上的话：

1. **Gate 上**
   - 给机器人单开一个子账户，只转进机器人的预算
   - 新建 APIv4 key：只开「现货」读写；提现、合约、杠杆、理财全部关掉
   - 绑 IP 白名单，填下面那台电脑的公网 IP。不绑 IP 的 key 90 天自动失效；每个 key 最多绑 20 个 IPv4
2. **找一台自己的电脑 / 服务器当 runner**（装好后在 Actions 里跑一次「Runner 体检」，会告诉你这台机器的公网 IP、能不能连上 Gate、时钟准不准）：仓库 Settings → Actions → Runners → New self-hosted runner，照着装好、保持开机（Linux / macOS 直接用；Windows 要先装 Git for Windows，workflow 用的是 bash）
   - 机器人**拒绝在 GitHub 托管的机器上跑实盘**：那些机器在美国机房、IP 每次都变，绑不了白名单，而 Gate 把美国列为受限地区
   - 用自托管 runner 时**务必把仓库改成私有**：公开仓库谁都能提 PR，等于能在你电脑上跑代码
3. **GitHub 配置**
   - Secrets：`EXCHANGE_API_KEY`、`EXCHANGE_API_SECRET`
   - Variables：`RUNNER` = `self-hosted`、`BOT_MODE` = `live`
4. **先空跑一次**：Actions → 梭哈机器人 → Run workflow，勾上「只看信号」。Summary 里会有 API key 体检（绑没绑 IP、账户实际费率、是不是统一账户）和每个机器人的信号。没问题再设 `BOT_ENABLED` = `true`——模拟盘默认开着，**实盘的定时任务必须显式打开**，不然机器人会拒绝。
5. 对照组（`paper_only = true` 的囤币和猴子）在实盘模式会自动跳过，不会碰真钱。`[live] max_order` 是单笔买入上限，先设小点。

想先用假钱走一遍真实下单流程：Gate 有测试网（testnet.gate.com，建 key 时账户类型选 Testnet），把 key 放进 `EXCHANGE_TESTNET_API_KEY` / `EXCHANGE_TESTNET_API_SECRET`，`BOT_MODE` = `testnet`。测试网同样只在自托管 runner 上跑。

## 配置

全部在 [`config.toml`](config.toml)，改完 push 就生效。每个 `[[bots]]` 是一个独立机器人：

```toml
[[bots]]
name = "btc-momentum"       # 名字（小写字母/数字/-/_），状态文件按它存
symbol = "BTC/USDT"         # 交易对，Gate 上有的现货都行，包括 NVDAX/USDT 这类股票代币
timeframe = "1d"            # K 线周期（研究结论：只用日线）
strategy = "tsmom"          # 策略名，见策略菜单
budget = 100                # 这个机器人能动用的钱（计价币）
size = 1.0                  # 梭哈系数：信号满格时用多少比例的资金，1 = 梭哈
params = { lookback = 14 }  # 策略参数，不写就用默认值；写错名字会直接报错
risk = { kill_switch = 0.5 }  # 风控，见下表
```

风控参数（都写小数，0 = 不启用）：

| 参数 | 意思 |
|---|---|
| `stop_loss` | 跌破持仓成本这么多就割（0.15 = -15%） |
| `take_profit` | 赚这么多就落袋（0.5 = +50%） |
| `trailing_stop` | 从持仓以来的最高价回撤这么多就走 |
| `kill_switch` | 净值跌到预算的 `1 - kill_switch` 就清仓罢工（0.5 = 亏一半收手）；复活见下面的 `reset` |

止损 / 止盈 / 移动止损触发后会进入**冷静期**：策略信号先归零一次才允许重新上车，免得刚割完肉下一小时又原价追回去。

轮动机器人写 `symbols` 列表、不写 `symbol`：

```toml
[[bots]]
name = "alt-rotation"
strategy = "rotation"
symbols = ["BTC/USDT", "ETH/USDT", "SOL/USDT", "DOGE/USDT", "GT/USDT"]
timeframe = "1d"
budget = 100
params = { lookback = 30, margin = 0.10 }
risk = { kill_switch = 0.5 }    # 轮动只支持 kill_switch
```

其他开关：

- `enabled = false`：暂停某个机器人
- `paper_only = true`：只在模拟盘跑
- `slippage = 0.001`：给盘口薄的标的单独设滑点（模拟盘和回测用）
- `liquidate = true`：**卖光收工**——下次运行把手里的全卖掉，之后不再买（实盘的一键清仓）
- `reset = "2026-11-01"`：**清空账本重新开始**（熔断后复活也用它）。写一个新值，下次运行就从 `budget` 重新算起；同一个值只生效一次，下次想再重置就换个值。实盘要先空仓才允许重置
- `budget` 可以随时改：加预算就补现金；减预算按比例从净值里抽（亏了 30% 的机器人砍一半预算，收益率还是 -30%，不会被推上熔断线）

## 推送

GitHub Secrets 里配哪个就用哪个（国内推荐微信的两个）：

| 渠道 | Secrets | 去哪拿 |
|---|---|---|
| Server酱（微信） | `SERVERCHAN_SENDKEY` | sct.ftqq.com（SCT 开头）或 Server酱³ App（sctp 开头），两种都支持 |
| PushPlus（微信） | `PUSHPLUS_TOKEN` | pushplus.plus |
| Telegram | `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` | @BotFather（手机上看要翻墙） |
| Bark（iPhone） | `BARK_KEY`，自建服务器再加 `BARK_SERVER` | Bark App |

只有成交、触发止损 / 止盈 / 熔断、出错时才推，平时不吵。配好后：Actions → 梭哈机器人 → Run workflow → 勾「只发一条测试推送」。

## 那些坑

- **手续费才是最大的对手**。Gate 现货每边 0.1%~0.2%（公开接口写 0.2%，帮助中心写 VIP0 是 0.1%，以账户实际为准），一买一卖 0.2%~0.4%。1 小时级别来回折腾的策略，回测里基本都被手续费吃干了（看排行榜里猴子的下场）。想高频，先把费率降下来（GT 抵扣 / VIP），再在 `config.toml` 的 `fee` 里改成真实费率重新回测。
- **GitHub 的定时任务不准时**。cron 写的是每小时第 7 分钟，实际可能晚几分钟到几十分钟，高峰期偶尔直接跳过一次。机器人按“目标仓位”设计，晚了就晚了，不会乱下单；但别指望它做秒级止损。
- **Gate 的 K 线历史有限**：每个周期只能往回查约 10000 根 —— 1h 大概 14 个月，4h 大概 4.5 年，日线不受影响。策略需要的 K 线根数（warmup）最多 990 根。
- **仓库是公开的**：`bot-data` 分支里的账本、成交记录所有人都能看到（不含任何密钥）。介意的话把仓库改成私有；私有仓库每月有 2000 分钟免费 Actions 额度，每小时跑一次大约用 700~1500 分钟，爬虫每 3 小时一次再加 ~250 分钟，够用但别再加别的了。
- **公开仓库 60 天没动静，GitHub 会自动停掉定时任务**。机器人每小时往 `bot-data` 提交一次，算“有动静”；如果你关掉了 `BOT_ENABLED` 又很久不碰仓库，记得回来点一下。
- **同一个账户跑多个机器人**：可以交易同一个币（各记各的账、卖出不会超过自己那份），但预算加起来别超过账户余额；你手动卖币时机器人分不清卖的是谁的。最省心的做法是给机器人单开一个子账户。
- **复活 / 重置**：用 config 里的 `reset = "新值"`，别去删 `bot-data` 分支里的状态文件——状态文件里记着这个机器人认领过的订单，删了以后对账会把最近的旧订单当成漏记的再认一遍。
- **恐惧贪婪指数晚一天**：日线机器人用的是“这根 K 线收盘前已经发布”的指数，也就是前一天的值，回测和实盘同一个口径，保证不偷看未来。
- **模拟盘不是实盘**：模拟盘按实时价格 + 手续费 + 滑点假装成交，不会考虑盘口被你吃穿。几百刀在 BTC/ETH 上无所谓，在小币和股票代币上会偏乐观。
